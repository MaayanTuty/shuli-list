# רשימת לידה

אפליקציית רשת קטנה להתארגנות לקראת לידה: ציוד לבית, תיק לידה, מעקב הוצאות ודשבורד.
נפתחת בנייד כמו אפליקציה (הוספה למסך הבית), עובדת גם בלי אינטרנט, והנתונים נשמרים במכשיר בלבד.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | שלד העמוד |
| `styles.css` | העיצוב |
| `app.js` | הלוגיקה: רשימות, הוצאות, דשבורד, גיבוי, ייצוא לאקסל |
| `seed.js` | רשימת ההתחלה (נטענת רק בהפעלה הראשונה) |
| `shuli.js` | שולי התחשית, מצוירת ב-SVG |
| `sw.js` | שירות רקע לעבודה בלי אינטרנט |
| `manifest.webmanifest`, `icons/` | התקנה למסך הבית |
| `fonts/` | הגופנים Assistant ו-Varela Round (רישיון OFL) |

## פרסום גרסה חדשה

1. מעלים את מספר הגרסה ב-`sw.js` (`VERSION`) וב-`app.js` (`APP_VERSION`). בלי זה המכשירים ימשיכו להציג את הגרסה השמורה.
2. `git commit` ו-`git push`. GitHub Pages מתעדכן תוך דקה או שתיים.
3. בפתיחה הבאה האפליקציה מורידה את הגרסה החדשה ומציעה לרענן.

הנתונים של המשתמשים לא נמצאים כאן ולא מושפעים מעדכון גרסה: הם שמורים בדפדפן של כל מכשיר.

## הרצה מקומית

כל שרת סטטי מתאים, למשל `python -m http.server` בתיקייה הזאת, ואז `http://localhost:8000`.
